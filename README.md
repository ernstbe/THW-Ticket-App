# THWTicketApp

This is a .NET MAUI app scaffolded on October 4, 2025.

## Getting Started

- Open the project in Visual Studio Code or Visual Studio.
- Build and run the app using the .NET CLI or your IDE.

## Project Structure
- `THWTicketApp.csproj`: Main project file
- `MainPage.xaml`: Main UI page

## Requirements
- .NET 8.0 or later
- .NET MAUI workload installed

## How to build
```
dotnet build
```

## How to run
```
dotnet run
```
